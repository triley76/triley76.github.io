# Riley Platforms portfolio site

A lightweight, responsive portfolio site for Timothy Riley. It is designed for GitHub Pages and requires no build process.

## Publish with GitHub Pages

1. Create a public GitHub repository named `triley76.github.io`.
2. Copy `index.html`, `styles.css`, `script.js`, and this README into the repository root.
3. Commit and push the files to the `main` branch.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

The site will appear at `https://triley76.github.io` after GitHub finishes the initial deployment.

## Add the custom domain later

After purchasing `rileyplatforms.com`, add it under **Settings → Pages → Custom domain**. GitHub will display the DNS records that must be created with the domain registrar.
